# Predict Calorie Expenditure
## Playground Series - Season 5, Episode 5

This repository provides a practice solution for predicting podcast listening time. The competition is intended for practice purposes on Kaggle. You can find the competition details [here](https://www.kaggle.com/competitions/playground-series-s5e5).

## Prerequisites

Before running the notebooks, ensure the following:
- Python 3.7 or higher is installed.
- Install dependencies using `requirements.txt` with pip, or create an environment using `environment.yml` with Anaconda.

## Instructions for Running Python Notebooks Locally

1. **Install Dependencies**  
    - Use pip:  
      ```bash
      pip install -r requirements.txt
      ```  
    - Or create an environment with Anaconda:  
      ```bash
      conda env create -f environment.yml
      conda activate <environment_name>
      ```

2. **Download Data**  
    Download the train and test datasets from the [Kaggle competition page](https://www.kaggle.com/competitions/playground-series-s5e5/data) and place them in the `data` folder.

3. **Run Notebooks**  
    Open and run the Jupyter notebooks using your preferred environment, such as Jupyter Notebook, JupyterLab, or VS Code. Feel free to explore and modify the notebooks to experiment with different approaches!
