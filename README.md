# Kaggle

This repository contains my contributions to the Kaggle community. These projects were completed for academic, self-learning, and hobby purposes.

## Contents
- [Titanic - Machine Learning from Disaster](Titanic_Survival_Prediction): Build a model to predict which passengers survived the Titanic shipwreck using a random forest classifier.
- [Binary Prediction of Poisonous Mushrooms](Binary_Prediction_of_Poisonous_Mushrooms): Classify mushrooms as edible or poisonous based on their physical characteristics.
- [Predict Podcast Listening Time](predict_podcast_listening_time): Estimate the listening time of a podcast episode.

## Prerequisites
To set up the environment, you can either use `pip` or `conda`. Follow the instructions below based on your preferred method.

### Environment Setup with pip
1. **Install Python:**
   Ensure you have the latest version of Python installed. If not, download and install it from the [official Python website](https://www.python.org/). For detailed installation guides, refer to:
   - [Installing Python on Windows](https://www.geeksforgeeks.org/how-to-install-python-on-windows/)
   - [Installing Python on Linux](https://www.geeksforgeeks.org/how-to-install-python-on-linux/)
   - [Installing Python on macOS](https://www.geeksforgeeks.org/how-to-download-and-install-python-latest-version-on-macos-mac-os-x/)

2. **Install Required Packages:**
   Run the following command to install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Environment Setup with Conda
1. **Install Anaconda:**
   If Anaconda is not already installed, download and install it from the [official Anaconda website](https://www.anaconda.com/). For detailed installation guides, refer to:
   - [Installing Anaconda on Windows](https://www.geeksforgeeks.org/how-to-install-anaconda-on-windows/)
   - [Installing Anaconda on Linux](https://www.geeksforgeeks.org/how-to-install-anaconda-on-linux/)
   - [Installing Anaconda on macOS](https://www.geeksforgeeks.org/how-to-install-anaconda-on-macos/)

2. **Create the Conda Environment:**
   Use the following command to create a new environment from the `environment.yml` file:
   ```bash
   conda env create -f environment.yml
   ```
   This will install all the dependencies specified in the `environment.yml` file.
